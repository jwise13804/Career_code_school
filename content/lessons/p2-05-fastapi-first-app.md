## What this lesson covers

- Installing Python and VS Code (both free)
- Virtual environments: a clean box of libraries per project
- `@app.get("/customers")` and running `uvicorn main:app --reload`
- FastAPI's automatic interactive docs at `/docs`

```analogy
FastAPI is like a well-designed case system: you describe what each request should do, and it handles the routing, the forms and the paperwork.
```
