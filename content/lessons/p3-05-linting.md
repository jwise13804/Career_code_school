## What this lesson covers

- Linters (find likely bugs) vs formatters (tidy layout)
- Ruff, a fast and popular Python linter and formatter
- Running it locally and in GitHub Actions
- Agreeing team style once, so nobody argues about it again

```analogy
A spellchecker and house style guide for code: it catches the small stuff, so reviewers can focus on the substance.
```
