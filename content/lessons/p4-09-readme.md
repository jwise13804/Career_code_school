## What this lesson covers

- What it is, why you built it, how to run it
- Design decisions: idempotency, pence, ledger, state machine
- What you'd add next and what you learned
- Small touches: a CI badge and a screenshot of `/docs`

```analogy
A great README is a great handover note: someone new can pick the project up and understand it without asking you anything.
```
