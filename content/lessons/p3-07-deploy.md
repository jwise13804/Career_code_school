## What this lesson covers

- From image to running service: registries and container services
- Options such as Azure Container Apps or Container Instances, AWS App Runner, and simpler hosts
- Environment variables and secrets in the cloud
- Budgets and alerts: protecting yourself from bills

```analogy
Deploying is like opening a new branch: same procedures (your container), new building (the cloud), and a manager watching the costs.
```
